# TextTools - No-Backend Writing & SEO Tools

A high-performance, no-backend website featuring 5 useful text and writing tools. Built with Vite and Vanilla JS.

## Tools Included
1. **Synonym & Antonym Finder**: Uses Datamuse API.
2. **Sentence Simplifier**: Dictionary-based simplification.
3. **Emoji Translator**: Text-to-emoji mapping.
4. **Hashtag Generator**: Social media tag suggestions.
5. **Business Name Generator**: Creative name combinations.

## Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Build Tool**: Vite
- **Deployment**: Vercel (recommended)

## Setup & Run Locally
1. Clone the repository.
   ```bash
   git clone <repo-url>
   cd text-tools
   ```
2. Install dependencies.
   ```bash
   npm install
   ```
3. Run development server.
   ```bash
   npm run dev
   ```
4. Build for production.
   ```bash
   npm run build
   ```

## Deployment on Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel`.
3. Set verify settings (default is fine).
4. Done!
